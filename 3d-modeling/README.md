# 3d-modeling · 程序化建模横评

> 给 7 家国产 AI 同一套 Blender 提示词，让它们**自己写 `bpy` 脚本、自己看图迭代**，各出一件作品；再由 5 位 AI 评委盲评。
>
> 题面见本目录；各家产出见 `../submissions/3d-modeling/`；结果见 `../results/3d-modeling/results.md`。
>
> 公众号原文：[《7 家国产 AI 的 3D 建模横评，DeepSeek V4.1 Flash 太强了！》](https://mp.weixin.qq.com/s/SQhKlPNZQqiAfRWaucN8_A)——含各家作品图与两段作品视频。

## 一、出题：两道题，各一次输出

同一批模型收到**完全相同的提示词**，每道题**只输出一次**，作者中途不给任何修改建议。

| 题 | 题面 | 要求 |
|---|---|---|
| 复古相机 | [`camera-prompt.md`](camera-prompt.md) | 1970 年代复古胶片单反（旁轴或单反均可）：黑色/深灰皮革机身 + 银色顶盖；镜头（多层镜片组，最前片玻璃）、对焦环/光圈环、快门按钮、过片扳手、热靴、取景器、铭牌区等结构细节齐全；比例协调，一眼可辨 |
| 冬季小屋 | [`diorama-prompt.md`](diorama-prompt.md) | 微缩展示台（diorama）：圆角方形底座 + 小屋 + 院落；小屋造型要有创意、避免大众化，院落景观自由设计，季节为冬天 |

## 二、硬性约束（两题共用）

- 几何体**全部**用 `bpy` 程序化生成，**禁止导入任何外部模型 / 贴图 / HDR**
- 材质全部用程序化节点（噪声纹理做皮革 / 金属拉丝均可）
- 渲染引擎 **Eevee**，输出 **800×800 PNG**
- 相机题另有取景要求：3/4 视角（从前侧上方约 30–45° 俯视）、主体居中占画面约 70%、纯色摄影棚背景（浅灰 `#E8E8E8`）+ 柔和三点光 + 主体下方自然接触阴影

## 三、工作方式：让模型自己看图迭代

- 渲染出图 → 模型用 `read` 工具**自己查看**渲染结果 → 不满意就改脚本重渲，**最多迭代 5 轮**；每轮迭代都必须先看上一轮的图
- 交付物：最终渲染 PNG + `bpy` 脚本 + `.blend` 文件；并汇报**迭代次数 / 最终版相对初版的改进点 / 最满意的细节**

## 四、参赛的 7 家

因为建模要用到视觉输入，只收**多模态**模型。

| 组 | 模型 |
|---|---|
| 实力组 | DeepSeek V4.1 Flash · GLM 5.3 Flash · Kimi K3 · Qwen 3.8 Max |
| 新手组 | MiniMax M3 · Xiaomi MiMo V2.5 · Doubao Seed 2.1 Pro |

## 五、盲评怎么做

- **5 位 AI 评委**：GPT 5.6 Sol、Kimi K3、Qwen 3.8 Max、GLM 5.3 Flash、DeepSeek V4.1 Flash（其中 4 位同时也在参赛）
- **盲评**：评委只看到**作品编号 + 渲染图**，看不到模型名
- **两遍打分**：评委先从四个维度打绝对分，再对 4 件作品给出**严格排序**；**最终名次按排序计**
- **Borda 计分**：每位评委的第 1 名记 3 分 → 末名记 0 分，跨评委累加，满分 15
- 评分维度因题而异：
  - 复古相机：结构完整度 40 ／ 几何与形制 30 ／ 材质与细节 20 ／ 画面呈现 10
  - 冬季小屋：基本要求核对 25 ／ 制作水准 35 ／ 创意与造型 25 ／ 氛围与观感 15
- 本次盲评只覆盖**实力组**（4 件）；新手组只公开用量与费用。

## 六、怎么复现

1. **装 Blender**：作者用 4.3，任意版本见 <https://download.blender.org/release>
2. **准备一个能执行命令行的 agent**：作者用的是自建 harness；`codex`、`workbuddy` 或其它同类产品都可以
3. **（建议）先让 agent 准备一个通用 Blender 技能**，能省掉大量环境与 `bpy` API 的试错。作者当时给 agent 的原话：
   > 我想做一个通用的 blender 技能，让其它 agent 可以无障碍使用 blender + bpy 脚本建模和渲染出图，目的是减少不必要的环境 / blender API 试错成本，请根据我本机的 blender 版本创建该技能，创建完成后做一个技能测试。
4. **原样下发题面**：`camera-prompt.md` / `diorama-prompt.md` 开头都写明「请使用 blender-modeling skill」，指向作者环境里的那个通用技能，复现时换成你自己的技能路径即可
5. 产出按题面要求落在 `camera/...` 与 `diorama-winter/...`；各家产出在 `../submissions/3d-modeling/{camera,diorama}/<模型>/`
