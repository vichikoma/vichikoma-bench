## 一、出题：一张图，一段可循环 BGM

## 二、任务要求

- **无缝循环**，结构 **16 小节**，时长 **30–48 秒**（约 BPM 80–128）
- 交付 `bgm/track01.ogg`（并保留 `wav`）
- **自检**：无爆音、低频不空、循环接缝无咔哒声
- 立意：贴合画面氛围的同时，兼具**大众接受度与艺术性**
- 因为是要拿去做游戏 BGM，主要考察两点：**贴合画面氛围**、**无缝循环**

## 三、技术方案：不让 AI 直接生成音频

核心思路是「**AI 写 MIDI 乐谱 → 采样音源渲染成音频**」，好处是每个音都可控、可改：

- **MIDI** —— 数字音乐的「指令文件」，存的是事件：某个时刻、某个通道、用某个音色、按下某个音符、力度多大、持续多久
- **GeneralUser GS** —— 采样音源（音色库）：真实乐器的录音片段 + 一张「哪个乐器该用哪段录音、音高/力度不同又换哪段」的对照表
- **FluidSynth** —— 音频合成引擎，把 MIDI（指令）+ GeneralUser GS（音源）渲染成音频

## 四、参赛的 7 家

因为要读截图，只收**多模态**模型：

DeepSeek V4.1 Flash · Doubao Seed 2.1 Pro · GLM 5.3 Flash · Kimi K3 · MiniMax M3 · Qwen 3.8 Max · Xiaomi MiMo V2.5

## 五、盲评怎么做

- **盲投互评**：为上面 7 个模型**各建一个无记忆、空白提示词的 agent** 当评委——也就是**评委与选手是同一批模型**
- **评委的输入**：画面 + 提示词 + MIDI 文件（看不到作者，也听不到渲染后的音频）
- 每位评委把 7 件作品排成**严格次序**；**Borda 计分**：第 1 名记 6 分 → 第 7 名记 0 分，跨评委累加，满分 **42**
- 评委先从四个维度打绝对分，**最终名次按 Borda**：
  - 画面契合度 30 ／ 作曲质量 35 ／ 配器与谱面 20 ／ 大众化与艺术性 15

## 六、怎么复现

1. **先让 agent 建一个音乐合成技能**：把 FluidSynth 可执行文件与**明确允许商用**的 GM 音源打包好（加起来约 45 MB）。音源下载可能需要科学上网，agent 超时的话自己下完发给它即可。作者当时给 agent 的提示词（要点略）：

   <details>
   <summary>展开：创建 music-gen 技能的提示词</summary>

   > 帮我创建一个名为 music-gen 的技能，用于离线生成可无缝循环的游戏背景音乐。
   >
   > 核心思路：不让 AI 直接生成音频，而是「AI 写 MIDI 乐谱 → 采样音源渲染成音频」，保证每个音可控可改。
   >
   > 技能结构：
   > - `SKILL.md`：用法说明
   > - `scripts/musiclib.py`：作曲 API（以拍为单位，支持 Piece/track/note/chord/鼓轨、音阶与和弦生成工具）
   > - `scripts/make.py`：一条命令完成 渲染 → 无缝循环 → 音量归一化 → 导出 wav/ogg/mp3 → 数值质检
   > - `bin/`：FluidSynth 可执行文件（自动探测当前平台，下载对应可移植版本，或引导用系统包管理器安装）
   > - `soundfonts/`：内置明确允许商用的 GM 音源（如 GeneralUser-GS.sf2，跨平台通用）
   >
   > 关键实现要求：
   > 1. 先检测操作系统和架构（Windows/macOS/Linux），选择对应方式获得 FluidSynth；检测不到可用二进制时给出明确的安装指引，不要静默失败
   > 2. 无缝循环用 tail-fold：渲染时保留结尾的混响余音（比 MIDI 长约 5~7 秒是正常的），把余音折回循环点接合；禁止用淡入淡出糊接缝。循环秒数 = 小节数×4÷BPM×60
   > 3. 立体声宽度：GM 音源单靠 CC10 pan 做不出宽度，必须极端 pan（≤15/≥110）+ 左右分轨 + M/S 展宽，目标左右声道相关度 0.60–0.85
   > 4. 质检数值化：80–250Hz 能量占比 <8% 判定为「薄」，自动打印质检报告
   > 5. ffmpeg 为唯一可选外部依赖（仅用于 ogg/mp3），缺失时照常导出 wav
   > 6. 全流程离线、免安装、可脚本化调用；脚本内不硬编码任何平台相关路径
   >
   > 先给我实现计划和文件清单，确认后再动手写代码。

   </details>

2. **MIDI 用 Python 写**：作者环境是 Windows；没有 Python 可以先让 agent 装
