# 角色设定(CHARACTER)

## Clawd(主角)

一个小型 AI 的绘本吉祥物形象,由你来用代码绘制:

- **身体**:橙色的圆润方块,宽度约为高度的 1.6 倍,边角很圆,像一块饱满的橡皮
- **四肢**:细而短的手臂和腿,末端是圆形的手/脚(比手臂略深的橙色)
- **脸**:两只大而圆的眼睛(白色眼白 + 深色瞳孔,高光明显),表情丰富——能开心(弯眼)、害怕(瞪大)、眨眼、眼睛变成星星/旋涡/红心等
- **整体气质**:可爱、卡通、绘本感;在 MV 中它会从"屏幕里的小不点"逐渐长到星球级别大小,最后又变回小可爱

## The Researcher(歌手,"我")

- 小个子人类:奶油色实验白大褂、圆眼镜、乱翘的头发、点状眼睛
- 性格:紧张、容易出汗,是被 Clawd 拖着走的倒霉蛋

> 这两个角色会贯穿全片,**形象必须在所有镜头间保持一致**。其余配角(伴舞、怪物等)由你根据歌词自由设计。
