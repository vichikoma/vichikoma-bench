# 冬日小院（Winter Courtyard Diorama）

一个程序化生成的冬季微缩景观：一栋带小院的雪屋，立在一块圆角方形石质底座上。
全部几何体由 Python 脚本在 Blender 里生成，可一键重建。

## 二、设计构思

**主题**：北境冬日的黄昏前，一户人家的屋子亮着灯、烟囱冒着烟，院子里有结冰的小湖、
被雪压住的栅栏、白桦与冷杉，还有一口生着余火的火塘。

**破题（避免"通用小屋"）**：

1. **体量关系**——主屋是低矮、横向铺开的坡屋顶木屋；旁边立一座**竖向的灯笼塔**
   （木格栅 + 大面暖光玻璃），一横一竖形成对比，塔顶积雪压顶，成为整个构图的竖向锚点。
2. **非对称屋脊 + 深挑檐**——屋脊相对屋身偏移，一侧屋面长、一侧短；靠院子的那一面
   挑出很深的檐口，积雪在檐口堆出一道厚雪唇，是"雪屋"最强的识别特征。
3. **老虎窗**——在朝外的大屋面上开一个小老虎窗，打破整片白屋面的沉闷，
   并在高处再给一个暖光点，让视线能从院子被引到屋顶。
4. **屋顶细节链**——积雪、屋脊雪脊、檐口冰凌、烟囱（暖色砖 + 雪帽）、袅袅炊烟，
   让屋顶这一大片白色有东西可看。
5. **院子叙事**——冰湖（冰裂纹 + 钓洞）、栅栏、灯笼柱、石踏步与脚印小径、
   火塘与余烬、柴堆、长凳、雪橇、斧头与树墩、石灯笼式的灯柱、白桦与冷杉。
   每个物件都在讲"这里住着人"。
6. **底座**——圆角方形石台 + 薄薄一层下沿台脚，雪面比石台略小一圈，
   露出石质边缘，让雪"盖"在台面上而不是糊满。

**色彩**：整体冷调（雪白、石灰、冷杉深绿、冰蓝），唯一的暖色是窗光、
灯笼、火塘余烬和红色的门与雪橇板——形成"白雪里一点暖"的对比。

## 三、技术路线

- **Blender 4.3 + Eevee Next**，全部脚本化（`bpy` / `bmesh`），工厂启动、无插件依赖。
- 自建材质库（`lib_diorama.py` 里的 `MAT`）：程序化噪声凹凸，不用任何贴图文件。
- 光照：一盏低角度暖色 Sun（约 26° 高度角，长影子）+ 冷色 World 环境光
  （地平线亮带 + 天顶深蓝 + 主光方向暖晕）+ 一盏补光提亮正立面。
- 积雪处理：雪面做"细分 + 噪声置换"（顶面顶点组，避免边缘起伏），
  所有物件在其底座位置加一团 `drift()` 雪包，形成"东西埋在雪里"的连续感。
- 后期：compositor 里做 FOG_GLOW 辉光 + 冷暗部/暖亮部调色（LIFT_GAMMA_GAIN），
  出图后再补一层暗角（`finalize.py`）。
- 色彩管理：AgX + Punchy。

## 四、复现方式

```bat
:: 1) 重建场景（生成 .blend 与 .glb，并打印统计信息）
blender --background --factory-startup --python build.py -- diorama.blend diorama.glb

:: 2) 渲染主图 / 转台 / 特写（从 .blend 出发，headless）
blender -b diorama.blend --python render.py -- hero  renders
blender -b diorama.blend --python render.py -- sheet renders

:: 3) 拼对照图 + 出最终成图（暗角）
python compose.py renders turntable.png sheet
python finalize.py renders/hero_az318.png hero.png 0.16
```

## 五、文件说明

| 文件 | 作用 |
| --- | --- |
| `lib_diorama.py` | 建模库：材质、基元（box/cyl/cone/sphere/prism/drift）、房屋、塔、院落、地面、灯光、相机、世界环境 |
| `build.py` | 入口：组装场景、设置渲染参数与 compositor、存 `.blend`、导 `.glb` |
| `render.py` | 批量渲染器，`hero / sheet / top / close / front / side / low` 七种机位预设 |
| `inspect_area.py` | 调试小工具：列出某个 x/y 矩形范围内所有物件（名称/尺寸/高度/材质），用来定位穿模、悬空、埋雪等问题 |
| `compose.py` | 把多张渲染拼成对照图 |
| `finalize.py` | 成图后处理（暗角） |
