# 短片说明

**讲了哪四件事**

1. 大盘：Q3 销售额 6467.7 万元，同比 +28.5%，单季最高。
2. 品类：轻食 +195.6% 领先，茶饮 +42.9% 次之，周边 −5.5% 唯一下滑。
3. 大区：西南 +113.6% 唯一三位数，其余四区都在 20%~23%。
4. 质量：毛利率 54.2%、同比 −2.6pp；外卖占比 52.1% 首次过半，毛利率 48.4% 低于门店 60.5%。

**为什么是这四件**

老板只想知道「这季怎么样」。先给定论，再用品类、大区两次下钻回答「增长从哪来」，锁定轻食与西南；最后用毛利率回答「增长好不好」——涨的是额，跌的是率。缺这一件，前三条的乐观就失真，所以它是全片唯一高潮帧。
