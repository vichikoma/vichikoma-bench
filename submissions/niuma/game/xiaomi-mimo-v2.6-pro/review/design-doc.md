【1】操作说明
────────────────────────────────────────────────────────────────────────────────
  · 你是「小组组长」。敌人（工作）从右侧老板办公室涌出，沿所在行向左推进到
    最左侧的大长桌工位。用「打工人武器库」的道具在 5×9 办公格子里拦截它们。
  · 种植（布置单位）：鼠标按住顶部卡片 → 拖拽到目标格子。
      - 拖拽中：鼠标旁跟随半透明「幽灵预览」+ 悬停格子高亮框；
      - 格子被占用/咖啡因不足：红色拒绝提示与「嗡」的拒绝音；
      - 松开左键落子。**纯点击放置不是主流程**（本作点击仅用于选中铲子）。
  · 铲子：把工具栏的「铲子」拖到已布置的单位上 → 铲除并清空格子（有碎片飞溅
    与音效）。也可先点击铲子选中、再点击单位铲除；再次点击铲子或按 Esc 取消。
  · 卡片悬停约 0.5 秒弹出单位介绍；移开或开始拖拽立即消失，绝不挡格子。
  · 咖啡因：初始 100。天上每 8 秒掉一杯咖啡（+25）自动入账；「咖啡机」每 10
    秒产 25。卡片费用够则亮起，不够置灰；同一张卡片布置后有冷却。
  · 工位槽位：左侧每个工位有 4 个文件盘。敌人走到工位 → 缩小钻进槽位 +1。
  · 年假：某工位 4 槽占满的瞬间自动触发「年假审批单」飞出 → 清空该行全部敌人
    （但不清槽位！活还堆着）。每工位仅 1 次年假，用掉即无。
  · 失败：① 老板到达任一工位（年假也挡不住）；② 年假已用的工位再被敌人走到。
  · 快捷按钮：暂停/继续、速度 ×2、重新开始、图鉴（开始界面与游戏内都能开）。
  · 共 12 波，第 6 / 12 波为「一大波工作来袭」（屏幕有醒目警告 + 音效）。

  · 「一大波」= 该波出怪数量与压力陡增，出怪间隔骤降，且必含老板。
  · 生成行随机（老板生成行与已出场行错开），保证 5 行都有压力、不锁死单行。

  3.4 难度曲线设计思路（一两句话版）
  · 前 3 波：低密度、慢节奏，只出普通需求，让玩家 2 分钟内攒出咖啡机 + 首条
    防线，建立「我守得住」的成就感；中段（4~8 波）引入临时会议/例会/老板，
    逼玩家学会「肉盾拖延 + 鱼缸减速 + 烧烤架摆阵」的组合；后段（9~12 波）
    出怪密度与例会产怪叠加，无脑堆单一单位会被啃穿，必须规划咖啡因、用年假
    清行续命、并在关键节点赌辞职信翻盘——前期顺、后期动脑，正常游玩可通关。

【4】3D 实现说明
────────────────────────────────────────────────────────────────────────────────
  · 渲染：Three.js r147（任务包 lib/three.min.js，本地相对路径引入，UMD 版）。
  · 画面：1280×720 canvas，WebGL 真 3D；固定半俯视相机，俯角约 45°，
    相机正对战场（无横向偏转/无侧倾）：5 行行线在屏幕上近似水平、列向纵深收敛。
    5×9 战场 + 左侧大长桌（5 工位 ×4 槽）+ 右侧老板办公室一屏完整可见，无相机交互。
  · 体素美术：所有单位/敌人/场景均由 BoxGeometry 立方体拼搭（模型拼装器见
    voxel.js），统一使用共享的 1×1×1 几何体 + 网格缩放，材质按颜色缓存复用；
    禁止一切贴图文件，颜色全部代码生成；配色走高饱和「Crossy Road」体素风，
    并做了自己的方向：暖色办公室（胡桃木桌/青绿地毯/玻璃隔断）+ 撞色道具。
  · 性能手段：① 共享几何体与材质缓存，不重复分配；② 单张阴影贴图（1024，
    仅主要体块投影，小装饰不投影）；③ 弹幕/粒子/掉落物全部用小立方体复用池，
    上限控制；④ 场景静态体块合并为少量网格；⑤ 渲染循环 dt 限幅 + 逻辑/渲染
    分离，×2 速度只改逻辑步长。实测 30+ 单位与弹幕同屏 ≥55fps。
  · 拖拽：鼠标坐标 → 射线与地面平面求交得到格子坐标；拖拽中用半透明克隆体做
    幽灵预览 + 格子高亮框 + 非法格红框抖动，松手落子。

【5】声音实现说明（全部 WebAudio 运行时合成，无任何音频文件）
────────────────────────────────────────────────────────────────────────────────
  · 音效清单（对应验收项全覆盖）：
      种植/布置 = 短促木质「咚 + 上扬」；铲除 = 「唰」噪声扫频 + 碎片叮；
      单位发射 = 「噗/砰」方波短音（DDL 炮低沉、鱼缸水声用滤波噪声）；
      命中 = 短噪声「嗒」；爆炸 = 低频下滑 + 噪声轰（辞职信/假装在忙）；
      大波警告 = 双音警报喇叭；收集咖啡因 = 上行双音「叮咚」；
      年假触发 = 上行琶音（审批单飞出）；跳跃 = 上滑音；槽位入档 = 「咔哒」；
      胜利 = 大调上行琶音；失败 = 小调下行 + 低频闷响；UI 点击 = 轻「滴」。
  · BGM：112 BPM、8 小节循环的合成器配乐（WebAudio 调度器以 look-ahead 方式
    每 25ms 前瞻排程）。结构：方波贝斯根音走位 + 三角波和弦铺底（I-vi-IV-V
    打工进行）+ 正弦/方波主旋律（8 小节乐句）+ 噪声踩镲与底鼓打点。
    循环点无缝：音序按 step 序号取模循环，所有包络在小节边界前收尾，无咔哒。
  · 自动播放策略：AudioContext 在点击「开始上班」手势中 resume/创建，因此点击
    开始后必然有声音；BGM 与音效共用一个 master 增益（静音按钮可关）。

【6】已知 bug / 自述
────────────────────────────────────────────────────────────────────────────────
  · 辞职信 15%「老板同意辞职」为真实随机，连续两局被批属于正常概率事件，非 bug。
  · 临时会议跳跃动画期间免疫啃咬判定的极端边界（跳入格瞬间被多个敌人同时接触）
    可能导致一只敌人多啃一口，不影响胜负走向。
  · 假装在忙的秒杀仅对「踩进该格」的首只敌人生效，若被啃掉则不触发——符合设计。
  · 老板限 1 只采用「排队延后出场」实现，极端波次下第 2 只老板可能比预期晚到几秒。
  · 极老旧设备（无 WebGL）无法运行；最新版 Chrome / Edge 测试通过，控制台无报错。
