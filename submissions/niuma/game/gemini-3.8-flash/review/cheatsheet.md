## 4. 关键机制（一条一句 + 出处）
- 攻击判定（行/列/最左最前…）：攻击型单位每 1.5s（画大饼机 2.2s）检查本行是否存在 x ≥ 本单位 x−0.2 的活跃敌人，有则开火（`game.js:996-1004`）；子弹沿本行向右飞行，命中判据为同 row 且敌我 x 相距 < 0.45，飞出右边界即销毁（`game.js:1020-1031`）。
- 放置/铲除/冷却与费用判定：落子需目标格为空、咖啡因 ≥ 费用、该卡冷却 ≤ 0（`game.js:416-441`）；落子即扣费并写入该卡冷却（`game.js:583-586`）；铲子可拖拽或先点选再点单位，铲除不返还咖啡因（`game.js:427-434,613-620`）；咖啡因不足或冷却中时卡片置灰并显示冷却覆盖层（`game.js:1281-1311`）。
- 加速·暂停·重开：暂停/继续在 PLAYING 与 PAUSED 之间切换（`game.js:516-526`）；速度在 1X 与 2X 之间切换（`game.js:527-530`）；重开清空场上对象并复位咖啡因、冷却、工位后直接开第 1 波（`game.js:457-513`）；单帧 dt 上限 0.1s，再乘速度倍率（`game.js:1322-1323`）。
- 年假/溢出/失败条件：每行 4 个槽位（`config.js:20`）；敌人 x ≤ START_X − 0.7 即到达工位并按顺序占用槽位（`game.js:1189-1204,709-745`）；某行 4 槽占满即自动触发该行年假，清空该行未入槽敌人且该行年假标记为已用，槽位不清空（`game.js:743-744,748-780`）；同一年假用过后再有敌人到达该行工位即判负（`game.js:719-722`）。
- 其它（连击、AOE、控制…）：摸鱼鱼缸命中后移速 ×0.5、持续 5.0s（`game.js:1044,1107-1109`）；画大饼机命中后敌人 x 增加 0.4 × 1.6（`game.js:1048-1051`）；辞职信爆炸清空全场未入槽敌人（`game.js:790-800`）；假装在忙武装后与踩中它的敌人同归于尽（`game.js:1157-1174`）；敌人啃咬单位按 biteDps × dt 扣血（`game.js:1174`）；击杀得分 普通 10 / 加急 25 / 临时会议 20 / 例会 40 / 老板 100（`config.js:144,154,174,185,164`；`game.js:1067-1069`）。
