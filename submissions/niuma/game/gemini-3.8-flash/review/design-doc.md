  1. 操作说明：
     - 布置单位：从顶部卡片栏按住卡片拖拽到目标网格单元格（显示半透明幽灵预览、悬停格子高亮及合法性检测），松开即可种植。
     - 铲除单位：将右侧「铲子」拖拽到场上已布置的单位上即可铲除（或点击铲子后点击单位）。
     - 卡片悬停：鼠标在卡片上悬停 0.5 秒展示详细属性 Tooltip；拖拽开始时立即自动隐藏。
     - 辅助控制：支持随时暂停/继续、1X / 2X 速度切换、随时重新开始本局、图鉴随时查阅。

  3. 最终波次配置与难度曲线设计思路：
     - 共 12 波：
       * 第 1~2 波：教学与铺场期，单只/少量普通需求缓慢入场，确保玩家能轻松建立 2~3 台咖啡机经济体系；
       * 第 3~5 波：渐进导入加急需求与具有跳跃机制的临时会议，检验玩家的背锅侠与多行布防能力；
       * 第 6 波：【一大波工作来袭】警告，首次引入会分娩需求的例会，高压测试玩家火力集中度；
       * 第 7~9 波：混合编队进攻，第9波老板初次登场进行视察，检验玩家的定点爆发输出；
       * 第 10~11 波：复合快慢怪混编高压阵，逼迫玩家合理运用假装在忙与鱼缸减速减缓阵线崩溃；
       * 第 12 波：【终极清算大波】全兵种混编狂潮，老板亲自带队压轴，考验全场资源与年假调度。
     - 难度曲线原则：前期成就感满满、后期需要缜密策略搭配，杜绝单一单位通关，非极限操作可稳定通关。

  4. 3D 实现与性能优化：
     - 渲染引擎：使用 Three.js r147 (本地 lib/three.min.js，离线可用)。
     - 几何与材质：共享 BoxGeometry(1,1,1) 单例网格，MeshLambertMaterial 材质缓存复用，避免任何运行时 DrawCall 爆炸。
     - 视角设定：固定半俯视 PerspectiveCamera(45°)，正对战场，严禁横向侧倾歪斜，左右完全对称。
     - 全程无外部贴图/纹理，纯体素拼搭与代码着色，同屏 30+ 单位与粒子稳定 60fps。

  5. 声音系统实现说明（Web Audio API 运行时合成，零外部音频）：
     - 音效覆盖：种植、铲除、收集咖啡因、子弹发射、击中反馈、爆炸音效、大波警报、敌人入槽、年假触发、胜利和弦、失败哀乐、跳跃音效。
     - BGM：32拍 124 BPM 无缝循环 Lo-Fi Chiptune 旋律，配备三角波低音、方波主旋律与轻快节奏点击，首击“开始”即解除浏览器音频封锁流畅播发。

  6. 已知 Bug 自述：
