# 作品 作品B — index.html 顶部设计说明（原样抽取）

================================================================
《植物大战僵尸 · 打工人版》 —— 3D 体素网页塔防 · 双击 index.html 离线即玩
玩家扮演小组组长：一波波"工作"从右侧老板办公室派发，穿过 5×9 办公区，
涌向左侧 5 个组员工位。调动打工人武器库（道具+倒霉同事）拦截它们。
================================================================
■ 操作说明
----------------------------------------------------------------
· 拖拽布置（默认方式）：按住顶部单位卡片 → 拖到网格格子松手落子。
  拖拽全程显示：①跟随的半透明幽灵预览 ②目标格高亮框（绿=可放，
  红=被占用）③无效落点报错音。
· 点选布置（辅助方式）：单击卡片选中（幽灵保持跟随）→ 再点格子落子。
· 铲子：把右侧「铲子」拖到任意我方单位上铲除（或点铲子后点单位）。
  铲子与卡片栏分区摆放、外观明显区分。
· 卡片悬停约 0.5 秒弹出单位介绍，移开或开始拖拽立即消失。
· 右键 / Esc：取消当前携带的工具。空格：暂停。
· ⏸ 暂停/继续 · ×1/×2 倍速 · 图鉴 · 重新开始（随时可主动重开）
· 敌人自动沿本行向左推进；走到工位前会"缩小钻进文件槽"，
  槽满 4 个自动触发该工位年假（清该行敌人、不清槽位、每工位仅 1 次）。
· 失败：①老板走到任一工位（年假挡不住）②某工位年假用掉后再来敌人。

■ 自创单位设计思路（各一句话）
----------------------------------------------------------------
★ 群聊@全体：标准武器库里缺"跨行补漏"手段——它把输出变成可在行间
  跳跃的消息链，专治"东一行西一行"的散兵潮，是阵型密度放大器。
★ 空调遥控器：全游戏缺一个"无伤害纯控制"位——一次冷风同时冻结一
  整段战线，给脆皮后排争取输出时间，也专门用来定住咬锅侠的空档。
  （两者机制均与"本行直线射手"完全不同型，不是 DDL 加农炮换皮。）

■ 难度曲线设计思路（两句话）
----------------------------------------------------------------
前 3 波只用宽间隔的普通/少量加急需求，两三门炮即可站稳，快速建立
"我守得住"的爽感；第 5 波老板登场后，临时会议跳防线 + 例会滚雪球
逼玩家混编经济/肉盾/减速/控制，并把年假当"最后一道闸"精打细算——
无脑堆单一单位撑不过第 8 波，正常运营搭配+留好年假可以通关。

■ 3D 实现说明
----------------------------------------------------------------
· 使用任务包内置 three.js r147（UMD 本地引用 lib/three.min.js），
  WebGL 渲染于 1280×720 canvas。固定半俯视相机：俯角约 46°、
  正对战场零横向偏转零侧倾（行线水平、列向纵深收敛、左右取景对称）。
· 体素风格：全部模型由代码把立方体拼成（顶点色烘焙面明暗，零贴图
  文件），美术对标 refs/crossy-road.jpg，并做了自己的"暖调办公室
  + 糖果撞色"配色方向。
· 性能手段：①静态场景（地板/网格/长桌/办公室/陈设）合并为 1 个
  不透明 mesh + 1 个玻璃 mesh；②每个单位/敌人为 1~4 个 draw call
  的小 Group；③全部粒子共用 1 个 InstancedMesh（1 个 draw call，
  上限 900 粒）；④阴影仅一盏方向光 2048 阴影贴图、只单位投影；
  ⑤pixelRatio 锁定 1、雾裁剪远景。高密度波次实测 60fps。

■ 声音实现说明（全部 WebAudio 运行时合成，零音频文件、零 base64）
----------------------------------------------------------------
· 音效清单：种植 / 铲除 / 加农炮发射 / 泼水 / 命中 / 爆炸 / 辞职清场 /
  一大波警告 / 老板警告 / 收集咖啡因 / 咖啡产出 / 年假触发 / 缩小入槽 /
  啃咬 / 单位被吃 / 武装完成 / 连锁@ / 冻结 / 点击 / 错误 / 胜利 / 失败
· BGM：约 104 BPM 的办公室放克 8 小节循环（锯齿贝斯+方波反拍+三角波
  口哨旋律+噪声 hi-hat/kick/snare），用 setInterval lookahead 精确按
  AudioContext 时钟排谱 → 循环处无缝无咔哒；大事件时自动压低音量。
· 点击"开始"（用户手势）里 unlock AudioContext，不受自动播放限制。

■ 已知 bug 自述
----------------------------------------------------------------
· 临时会议若正好在贴住单位时被铲掉目标单位，跳跃动画可能直接落地，
  属可接受的边缘情况。
· 例会产出的新需求在"该行走廊已被我方占满"时不会产出（按设计：
  只在空格生）。
· 假忙套装武装完成的屏幕闪烁与受击红闪同帧会互相覆盖，极小概率
  视觉闪烁一帧。
· 极端情况下（辞职信引爆瞬间老板恰好入槽动画中）清场判定跳过入槽
  中的敌人——但它们本来也会自行钻槽，不影响结果。
· 倍速 ×2 下 WebAudio 音效仍按事件播放，密集交火时可能觉得吵。
