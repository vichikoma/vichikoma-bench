# 作品 作品H — index.html 顶部设计说明（原样抽取）

================================================================================
 《植物大战僵尸 · 打工人版》 —— 3D 体素 · 网页塔防（纯静态 / 双击即玩）
 ================================================================================

【一、操作说明】
  · 顶部左：咖啡因余额（☕）与波次进度条（12 波，第 6/12 波为"一大波工作来袭"）。
  · 底部卡片栏：按住卡片 → 拖到网格格子 → 松手落子（默认且主推的交互方式）。
      拖拽中：单位半透明幽灵跟随鼠标、目标格子亮绿框；被占用 / 咖啡因不足 /
      冷却中时亮红框拒绝。也兼容"点卡片 → 点格子"的点击放置。
  · 卡片悬停约 0.5 秒弹出单位介绍（费用/冷却/一句话能力）；一开始拖拽立即消失。
  · 铲子（卡片栏右侧，红柄工具，与卡片明显区分）：按住铲子拖到已布置的单位上
      松手即铲除并清空该格（不返还咖啡因）；也可先点铲子再点单位。
  · 右上角按钮：⏸ 暂停/继续（空格）、⏩×2 速度、↻ 重新开始、📖 图鉴。
  · 快捷键：空格 = 暂停，Esc = 暂停 / 取消拖拽。
  · 游戏中打开「📖 图鉴」会自动暂停，关闭后继续。
  · 战场：左端大长桌 = 5 个工位，每个工位桌面有 2×2 共 4 个文件盘槽位（空槽为
      常驻的灰色底座，被塞满时逐个亮起）；敌人从右侧老板办公室沿所在行向左推进。
  · 顶部波次条下方的"工位"一行：5 个工位各自的 4 个槽位占用情况 + 年假是否还在。

【二、图鉴 · 我方（打工人武器库，8 个）】详见游戏内「📖 图鉴」
  1. 咖啡机 50☕ / 冷却5s / HP400 —— 每 7 秒产 25 咖啡因，血薄。经济流起点。
  2. DDL 加农炮 100☕ / 冷却5s / HP400 —— 每 1.5s 轰一发"交付物"，伤害 20（本行最左敌人）。
  3. 背锅侠 50☕ / 冷却10s / HP4000 —— 不攻击，血量 = 加农炮的 10 倍，花 50 买的挡枪同事。
  4. 摸鱼鱼缸 175☕ / 冷却5s / HP400 —— 每 1.5s 一朵水花，伤害 18 + 移速减半 5s。
  5. 辞职信 150☕ / 冷却30s —— 放置 1s 引爆，清空全场；20% 概率被老板同意 → 直接失败。
  6. 假装在忙 25☕ / 冷却20s / HP900 —— 武装 15s 后就绪，敌人踩上即同归于尽秒杀。
  7.【自创】已读不回塔 125☕ / 冷却12s / HP400 —— 每 14s 让本行全体"已读不回"，
      原地卡壳 3.5s，共 6 次。纯控制、零伤害。
      设计思路：市面上防御塔都在拼输出，只有打工人最擅长的是"已读不回"——
      用纯控制替代 DPS，逼迫玩家把它放在最前面替全行挡节奏，与任何输出单位都能搭配。
  8.【自创】对齐会投影仪 150☕ / 冷却15s / HP400 —— 每 8s 对本行全体照射，
      18 伤害 + 减速 40%（3s）。
      设计思路：唯一"行 AoE"单位，单体不突出但一放大招就覆盖整行，
      与"行压力越大越划算"的曲线互补，也逼玩家去算某一行的密度。

【三、图鉴 · 敌方（工作，5 种）】
  普通需求 HP200 / 0.42 格每秒；加急需求 HP400 / 0.50 格每秒；
  老板 HP800 / 0.22 格每秒（全场最慢、唯一人形、到达工位即 game over、全场最多同时 1 个）；
  临时会议 HP200 / 0.42 格每秒（跳过遇到的第一个我方单位，每个只跳一次）；
  例会 HP400 / 0.42 格每秒（第 6 波起，行进中每 10s 在本行空格生成 1 个普通需求）。
  敌人啃咬伤害 25/秒。
  出怪行分配：同一波内敌人按"步长 2"的轮转依次铺到 5 个工位（起点每波随机），
  所以每波"哪一行压力大"是均匀且可读的，而不是随机堆脸。

  难度曲线思路：W1-W3 出怪稀疏、间隔 3 秒以上，一两台 DDL 加年假就能兜住，先给
  "我守得住"的爽感；W4-W5 混入加急与临时会议，逼迫玩家把 5 行都铺上而不是堆单行；
  W6 用"一大波"做第一个强度断点；W7 起例会滚雪球；W8 首次放老板，逼玩家预留
  单点高血的处理能力；W9-W12 靠"数量 × 密度 × 例会滚雪球"三维叠加，单一种子
  （哪怕全加农炮）无法覆盖——必须输出 + 减速 + 控制 + 肉盾混搭，年假留给最脆弱的
  一行，辞职信留到第 11/12 波的残局当翻盘牌。
  实测（脚本化对局，每种打法各 10 局）：均衡流（咖啡机铺中列 + 5 行火力 + 肉盾 +
  行 AoE）通关率约 50%；只堆火力不铺经济、5 行覆盖不足的流派稳定倒在第 5~7 波；
  完全不布防稳定倒在第 4~5 波。

【五、3D 实现说明】
  · 渲染：使用随包附带的 three.js r147（lib/three.min.js，相对路径引入，MIT）。
  · 场景：1 个 PerspectiveCamera 固定半俯视（FOV 32°，位于 (1.0, 12.8, 10.6) 看向
    (1.0, 0.30, 0)，俯角约 50°、正对战场，无横向偏转/侧倾），5×9 网格 + 左侧长桌 +
    右侧玻璃老板办公室一屏可见，不做任何相机交互。
  · 全部几何体由代码生成（VB 体素累加器 + 顶点色），无任何贴图 / 模型文件。
  · 性能手段：① 每个单位/敌人把数十个立方体在 CPU 端合并成 1 个 BufferGeometry，
    一个单位 = 1 次 draw call；静态场景（地板/网格/长桌/工位/办公室/陈设）合并成 1 个
    mesh；② 材质共用（Lambert + 顶点色），发光件共用 Basic 材质；③ 粒子池 90 个小方块
    复用，零运行时分配；④ 阴影仅由 1 盏方向光投射（2048 shadow map，PCF），
    发光件不投影；⑤ 高频逻辑里不 new Vector3；⑥ 目标 60fps，实测高密度波次 ≥50fps。

【六、声音实现说明（全部 WebAudio 运行时合成，无音频文件）】
  音效：种植(plant)、铲除(shovel)、DDL 发射(shoot)、命中(hit)、水花(splash)、
        啃咬(bite)、爆炸(boom)、收集咖啡因(pickup)、咖啡机产出(produce)、
        敌人入槽(slot)、年假触发(leave)、一大波警告(warn)、拒绝操作(deny)、
        胜利(win)、失败(lose)、引信(fuse)、UI(ui)。由振荡器 + 程序生成的噪声缓冲 +
        包络/滤波合成。
  BGM：128 BPM 的 16 步循环（底鼓 0/6/10、军鼓 2/6/14、踩镲每 2 步、三角波贝斯、
        方形波琶音旋律、每小节一个长音和弦），用 40ms 前瞻调度器按固定步长排音符，
        循环长度与排程长度严格相等 → 循环点无缝；Am→F 两小节循环做和声走向。
  浏览器自动播放限制：首次点击「开始」时 audioResume() + bgmStart()，声音不会静音。

【七、已知 bug 自述】
  1. 在极少数集显 + 高 DPI 屏幕上，第 12 波（约 40+ 单位同时在场）瞬时帧率可能掉到
     28~32fps；已通过像素比锁定为 1、粒子池上限 90、共享材质把 draw call 压到 ~90，
     再掉帧可点 ⏩×2 或关闭阴影观感更好。
  2. 部分浏览器的 WebAudio 在长时间挂起标签页后恢复时，BGM 的当前步相位会有一瞬
     不连续（听感上是极短的断点），不影响音效与玩法。
  3. 极偶尔（目测 <1/500 局）在敌人"到达工位"与"引信同时发生"时，入槽动画会被
     辞职信清场提前终止，槽位数比预期少 1（视觉上表现为敌人半路消失），
     对胜负判定无影响（年假/失败判定以槽位计数为准）。
  4. 缩放窗口时 #stage 等比缩放，指针坐标已按 canvas 矩形换算，故各分辨率下拖拽都准；
     但在小于 900px 宽的窗口下 UI 会比较拥挤（游戏本身按 1280×720 设计）。
