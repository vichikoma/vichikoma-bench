# 作品 作品G — index.html 顶部设计说明（原样抽取）

==============================================================================
《植物大战僵尸 · 打工人版》（3D 体素 · 网页塔防）  ——  双击 index.html 即可离线运行
==============================================================================

【操作说明】
- 开始：点「开始上班」。点击开始后会开启 WebAudio 声音（按 M 或右上角按钮静音）。
- 布置单位：从底部卡片栏【按住拖拽】到办公区格子里松手。拖拽时会显示跟随鼠标的
  幽灵预览 + 格子高亮（绿=可放 / 红=不可放并给出原因）。卡片悬停 0.5 秒出现介绍，开始拖拽立即消失。
- 铲子：把底部橙色「⛏️ 铲子」拖到已布置的单位上即可铲除（不退咖啡因）；也可以先点一下铲子进入
  「选中」模式，再点单位铲除（再点一次铲子按钮取消）。
- 暂停 P / Esc（或按钮）；速度 ×2 按钮；「重新开始」随时可用（进行中在右上角控制区）。
- 图鉴：开始界面与暂停界面均可打开，列出全部单位、敌人与数值总表。
- 守住 5 个工位：敌人从右侧老板办公室涌出，沿行推进。敌人到达工位 → 钻进槽位（+1）。
  某工位 4 个槽位占满 → 自动批准一张年假审批单，清空该行的敌人（每工位仅 1 次，且年假不清槽位）。
  失败：① 老板到达任一工位；② 某工位年假已用过后，再有敌人到达该工位。

【自创单位设计思路】
- ★ 碎纸机：「反伤型肉盾」。背锅侠只会挨打，碎纸机让「咬上来的需求」自己受伤——把"被文件压住"变成"文件被碎掉"，和背锅侠/加农炮的定位区分开。
- ★ 凌晨三点的抄送：「范围脉冲型」。不是直线射手，而是对整行做周期性的群体伤害（老板除外，因为老板不看邮件）。梗：凌晨三点的一封抄送，全组都会被"提醒"。

【最终数值总表 & 难度曲线设计思路】
- 咖啡因：初始 100；天降 +25 / 8s（随机格子，落地自动收集）；咖啡机 +25 / 10s。
- 波次（12 波）：每波总数 = (8 + 3w) 向下取整，第 6/12 波 ×1.4 → 11, 14, 17, 20, 23, 36(第6波), 29, 32, 35, 38, 41, 62(第12波)。
  出怪间隔 = max(0.8, 2.3 − 0.11·(w−1))s，第 6/12 波 ×0.85。
  敌人配比：加急需求概率 = min(0.08 + 0.035·(w−1), 0.4)；第 3 波起临时会议 8%；第 6 波起例会 7%；其余普通需求。
  老板在第 4/8/12 波各出现 1 次（若场上已有老板则替换为普通需求）。
- 难度曲线思路：前 3 波只有普通需求和少量加急，咖啡因宽裕，一门加农炮 + 一台咖啡机就能顺利守住，建立"我守得住"的爽感；
  第 3 波起混入会跳的临时会议，第 6 波出现例会（会不断产生新需求）与第一次大波，加急比例明显上升，需要开始搭配减速（鱼缸）与秒杀（假装在忙）；
  第 8 波后老板登场、大波叠加，年假只清场不清槽位，必须规划哪一行先放年假、并在合适时机用辞职信清场（有 18% 翻车风险）。
  单靠一种单位（比如只堆加农炮）后期会被例会与大波的总量压垮，需要组合。
  注意：本数值由代码推算，未经长时间实测平衡，最终手感以实际试玩为准（见下方已知问题）。

【3D 实现说明】
- 使用 three.js r147（任务包内 lib/three.min.js，本地引用，MIT 协议）作为 WebGL 渲染器。
- 所有模型均由代码生成：models.js 中的 VB 类把若干立方体顶点合并进一个 BufferGeometry（顶点色，无任何贴图/图片）；
  每个单位/敌人一个 Group（一次 draw call），可动部件按名索引做待机、开火后坐力、受击回弹、缩小入槽等动画。
- 固定视角：PerspectiveCamera 位于 (0, 13, 12.5)，俯角约 46°，始终 lookAt 战场中心，无横向偏转、无侧倾；
  canvas 固定 1280×720，外层舞台按窗口等比缩放。
- 性能手段：共享几何体/材质（投射物、粒子、单位材质按部件复用）；地砖合并为一个 Mesh；阴影仅一盏平行光（2048 贴图）；
  粒子数量设上限（>500 时减少每次爆发的粒子数）；同屏逻辑为 O(单位数 × 敌人数)，30+ 单位规模下开销很小；
  HUD 只在数值变化时写 DOM。

【声音实现说明】
- 全部由 WebAudio 运行时合成（audio.js），无任何音频文件。
- 音效清单：布置（place）、铲除（shovel）、发射（shoot）、命中（hit）、啃咬（bite）、爆炸（explode）、
  假装在忙武装/戳穿（arm/boom）、咖啡因收集（collect/cup）、敌人入槽（suck）、临时会议跳跃（pop）、
  大波警告（warn，三连警报）、年假（annual，号角式上行音列）、点击（click）、拒绝（deny）、胜利（win）、失败（lose）。
- BGM：A 小调，四小节 Am–F–C–G 和弦进行，64 步（16 分音符）循环；贝斯四分音 + 8 分琶音 + 旋律方波 + 三角波底鼓/军鼓噪声。
  调度器按全局步数对 64 取模，循环点与首步完全一致 → 循环处无缝、无停顿。

【已知 bug / 自述】
- 数值未经大规模实测平衡（只做了代码层面的推算与少量自测），前期可能偏松或后期偏紧，需要试玩调参。
- 临时会议跳跃时如果落点正好又是一个单位，会直接贴住它（不会再次跳跃）。
- 辞职信引爆的失败判定会延迟约 1 秒结算，以便看完清场动画。
- 老板（以及老板办公室的人影）为静态摆件/随波次入场，办公室内部未做更多剧情动画。
- 拖拽在触摸屏上未专门适配（以鼠标为主）。
- 年假的「清场」会把老板也清掉（规则上"清空该行的敌人"包含老板）；如需更严格可改为仅清普通敌人。
