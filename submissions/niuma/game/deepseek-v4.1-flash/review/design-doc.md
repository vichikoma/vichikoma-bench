  植物大战僵尸 · 打工人版  (3D 体素 · 网页塔防)

  【一、操作说明】
    · 开始界面点「开始上班」进入游戏（点击同时解锁 WebAudio，BGM 与音效即刻响起）。
    · 布置单位：按住底部卡片栏的单位卡片，【拖拽】到中间办公区的格子上，松手落子。
        拖拽中会显示：①跟随鼠标的半透明幽灵模型 ②悬停格子的高亮框
                     ③不可放置时变红并提示原因（格子被占 / 咖啡因不够 / 冷却中）。
    · 卡片悬停约 0.5 秒弹出单位介绍（名称/费用/一句话能力），移开或开始拖拽立即消失。
    · 铲子（清理格子）：默认交互是【把铲子拖到】已布置的单位上松手 → 铲除并清空格子。
        拖动过程中铲子会跟随光标，悬停到可铲除的单位上时铲头会变金色高亮；
        也保留了「先点一下铲子选中、再点单位」的用法，两种方式铲除表现一致（灰尘特效 + 音效）。
    · 随时重开：右上角「重开」按钮可在任意时刻重置本局（点一次进入待确认态，3 秒内再点一次才真的重开，
        防止误触）；键盘 R 键是即时重开。局势没救的时候不必硬等失败结算。
    · 键盘：空格 = 暂停/继续，1/2 = 1 倍速/2 倍速，C = 图鉴，S = 铲子，M = 静音，R = 重开。
    · 顶部 HUD：左＝咖啡因余额与产出速率；中＝第几波 + 波次进度条 + 12 波进度点；
                 右＝暂停 / 2×速度 / 图鉴 / 音效 / 重开。
    · 左侧槽位面板实时显示 5 个工位的堆积情况与年假是否还在。

  【五、难度曲线设计思路】
    前 4 波只放慢速普通/少量加急，出怪间隔 6.0s→4.2s，玩家能安心起手 4~5 台咖啡机把经济滚起来，
    并有余裕试吃每个单位的机制，建立「我守得住」的爽感；W5 首次放老板（0.24 格/秒、42 秒才能走到工位），
    用「慢到离谱但一到就死」的压迫感教会玩家：单行火力必须够厚。W6 与 W12 是两次「一大波」断点，
    数量/间隔同时收紧（17 只 / 2.6s、27 只 / 1.7s），逼玩家把年假与辞职信这种一次性资源用在刀刃上。
    中后段每波开始掺入例会（持续在本行孵化新需求）与临时会议（跳过第一道防线），
    单靠「一行一门炮」的堆法会被跳过与侧漏打穿，必须搭配背锅侠卡位、鱼缸减速、假装在忙补漏，
    再用老板画的饼给核心行上攻速光环。整体节奏：W1-W4 教学 + 起经济，W5-W8 建立多行火力网，
    W9-W12 考验资源调度（咖啡因存量、年假次数、辞职信赌不赌）。正常游玩可通关，
    但「只堆一种单位」会在 W6 之后迅速崩盘，符合「前期有成就感、后期要策略」的目标。

  【六、3D 实现说明】
    · 使用 three.js r147（任务包内 lib/three.min.js，UMD 构建，MIT），WebGL 渲染在 1280×720 的 canvas 上。
    · 全部几何体由代码生成：自研体素构建器 js/voxel.js 把一堆立方体合并成单个 BufferGeometry
      （顶点色 + 逐面烘焙明暗系数），因此每个单位只需要 1~4 个 draw call。
    · 真 3D：PerspectiveCamera 固定半俯视视角，仰角 42°（符合 40°~50° 要求），
      位于战场正前方 x=0 平面上、镜头只做俯仰不做横向偏转与侧倾，网格行线水平、列向纵深收敛，
      5×9 战场与左侧大长桌一屏完整可见。整个游戏过程相机不旋转、不缩放。
    · 光影：HemisphereLight（天光/地面反射）+ 平行光（投射 2048² PCFSoft 阴影，阴影相机紧贴战场）
      + 两盏点光源做氛围；地面/桌面接收阴影。
    · 性能手段：几何体与材质全量共享、弹幕与粒子走对象池（零 GC）、
      固定帧步长更新、渲染像素比上限 1.5、阴影仅由实体单位投射（弹幕/粒子不投影）。

  【七、声音实现说明】（全部 WebAudio 运行时合成，零音频文件、零 base64）
    · 音效（振荡器 + 噪声缓冲 + ADSR 包络）：种植、铲除、加农炮发射、水花、邮件、命中、被啃、
      爆炸(辞职信)、地雷引爆、地雷武装完成、收集咖啡因、咖啡机进账、大波警告、老板登场、
      年假触发、工位堆积、按钮、无效操作。
    · BGM：112 BPM、8 小节循环的 C–Am–F–G（I-vi-IV-V）进行，方波主旋律 + 三角波贝斯 +
      锯齿波和声垫 + 噪声鼓组（底鼓/军鼓/踩镲）。用 WebAudio 前瞻调度器（lookahead 16 分音符，
      25ms 轮询）持续推进音符，从不 stop/start，因此循环处天然无缝、无咔哒。
    · 首次点击「开始上班」时 resume() AudioContext，避免浏览器自动播放策略导致全程静音。

  【八、自创单位设计思路】
    · 全员邮件（125 / 冷却20s / 血260）：
      「这事得让所有人都知道」，把邮件群发做成真正的跨行火力，每 7 秒给每一行的最左敌人各投递一封
      30 伤害的邮件。设计意图：标准射手只能守一行，遇到多行同时漏怪时完全无解；全员邮件用
      「面」覆盖补掉侧漏，但单行 DPS 只有 30/7≈4.3（远低于加农炮的 15.7），不能替代行内火力，
      只能作为补刀与救火，形成「横向覆盖 vs 纵向纵深」的取舍。
    · 老板画的饼（150 / 冷却25s / 血200）：
      把「画饼」这种抽象的精神攻击做成实打实的攻速光环——饼是假的，鸡血是真的。
      不攻击、不占输出，但让周围 3×3 内所有我方攻击单位攻速 +25%（不叠加）。
      设计意图：提供唯一的「增益/摆放决策」维度，鼓励玩家围绕核心行聚拢火力，
      而不是把单位平铺成一条线；同时血量只有 200，逼玩家把它放在背锅侠与鱼缸之后。

  【九、已知 bug 自述】
    1. 拖拽落子以鼠标位置为主：若把鼠标拖到画面外的 HUD 上松手，视为取消布置（不消耗咖啡因）；
       铲子拖拽同理——拖到战场外松手即取消，不铲任何东西。
    2. 「重开」按钮需要点两次（3 秒内）才生效，属于刻意的防误触设计，不是失灵；键盘 R 键无此二次确认。
    3. 临时会议跳跃落点固定为「跳过单位后 1.3 格」，极端情况下（连续两个单位紧贴且落点恰好落在
       第八列边缘）视觉上会有轻微重叠，但不会卡死，下一帧即恢复正常啃咬逻辑。
    4. 2 倍速下部分短音效（发射/命中）做了 40ms 节流，听感上会略有合并，属预期行为。
    5. 窗口极小（<600px 宽）时舞台等比缩小，卡片文字会变小但不会溢出。
    6. 年假清场的纸片飞行途中若该行敌人已被其他单位击杀，纸片会继续飞完动画再消失（仅表现层）。
    7. 游戏使用 WebAudio，个别浏览器在标签页切到后台时会挂起音频，切回后自动恢复。
