# 植物大战僵尸 · 打工人版

解压并打开本文件夹中的 `index.html`，点击「开始值班」即可游玩。全部代码和 Three.js 都在文件夹内，无需联网、服务器、安装依赖或构建。

- 按住顶部单位卡片，拖入办公区空格，松开布置。单位自动战斗。
- 拖拽铲子到已布置的单位上可移除，不退还咖啡因。
- 卡片悬停半秒查看能力。咖啡因不足或卡片冷却时无法布置。
- 空格暂停/继续。顶部提供 ×2 速度、声音开关、图鉴和随时重新开始。
- 前两波分别在前两行、前三行出现，第三波起开放全部五行。先发展咖啡机，再覆盖每行输出。
- 四份工作漏进同一个工位，会用掉这一行唯一的一次年假；年假清敌人，不清槽位。此后该行再漏一份工作便失败。
- 老板到工位立即失败，年假无法挡住老板。
- 辞职信会全场清空，但有 **15% 概率被批准而直接失败**。

共十二波，第六、十二波有大波警告。示例混合阵型约九分钟完成，×2 约四分半；实际时长取决于阵型与交付速度。

八种武器全部在游戏图鉴中：咖啡机、DDL 加农炮、背锅侠、摸鱼鱼缸、辞职信、假装在忙，以及原创的「已读不回」「会议静音器」。

`index.html` 顶部注释包含操作、完整最终数值表、波次编排、自创设计、3D 与声音实现说明及已知限制。验收情况见 `VALIDATION.md`。

建议最新版 Chrome 开启硬件加速，并使用桌面鼠标。画布固定为 1280×720，窗口会按比例缩放；没有旋转相机或缩放战场的操作。

Three.js r147 使用任务包提供的本地 MIT 版本，许可在 `lib/LICENSE.txt`。其余场景、模型、界面、声音和游戏逻辑均由代码生成，不包含外部图片、字体、音频或贴图。
