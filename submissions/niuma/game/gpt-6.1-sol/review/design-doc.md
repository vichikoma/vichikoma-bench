# 作品 作品A — index.html 顶部设计说明（原样抽取）

《植物大战僵尸 · 打工人版》 / 最终交付说明
操作：双击 index.html，点击「开始值班」；按住顶部卡片拖到空格，松开布置。
拖拽铲子到己方单位可移除（无退款）。卡片悬停 500ms 显示介绍。
空格暂停/继续；工具栏支持暂停、×2、静音、随时重新开始与图鉴。开始时激活 WebAudio。
固定正前方约 44° 半俯视相机；五行九列全屏可见。无视角操作。建议 Chrome、桌面鼠标。

首次出怪前12s准备，清波后7s休息；例会额外生成的需求不计上述波次数量。
第1波仅前两行，第2波前三行，之后五行轮换。第2波起每4只的第2只是加急；
第3波起每5只的第4只是临时会议；第6波起每6只的第3只是例会，第10波起改为每4只。
第8波起每2只的第2只是加急（优先级：老板＞例会＞临时会议＞加急＞普通）。
初始咖啡因200；天降每12s+25；咖啡机每10s+25；铲除不返还。
难度曲线：前两波逐步开放行数，给玩家部署经济与火力的时间；后半段增加加急、跨防线的
例会生成、跳跃与密度，要求多层防御、静音器与控场协同。低价雷用于预先守住后场。
槽位：每行4槽，非老板敌人缩小入槽0.65s后占用+1。占满立刻年假清本行非老板敌人，
保留全部4槽；每行仅1次。已用年假的行再次被突破则失败。老板抵达立即失败。
胜利：12波全部处理且场上、入槽动画都结束。统计：消灭数/咖啡因/剩余年假。

3D：使用本地 Three.js r147 UMD（MIT）。所有模型、粒子、地板、家具均由程序方块生成，
无贴图/图片/外链/base64资源。透视相机位于(0,16,16)，正对战场，无侧倾，无横向偏转。
固定1280×720 WebGL画布，CSS按比例缩放。体素面合并为顶点色 BufferGeometry，静态办公室
一次合批，共享单位几何体与材质，动态单位少量draw call，限制粒子数量，阴影1024。
卡片与图鉴造型为同一模型数据计算的内联SVG方块投影。无网络加载请求。
音效：布置、铲除、发射、命中、爆炸、大波警告、收集、年假、胜利、失败均为实时WebAudio。
BGM：96BPM、8小节的原创五声音阶旋律，低音与合成踩镲/底鼓，按AudioContext时钟提前
调度，32拍无缝循环，无音频文件。开局用户手势resume；暂停时音乐停止调度。
已知限制：小屏按16:9缩放，触屏可拖拽但桌面鼠标体验最佳；后台标签页自动暂停防止突然堆活。
未发现阻断游玩的已知bug；实际帧率受设备GPU影响。详细验收记录见 VALIDATION.md。
