# K 动画题 · 任务书

> 为角色 **CocoMon** 制作一套游戏常用的循环动画（Mixamo 风格），交付一个带动画的 `.blend` 文件。

## 一、任务

打开 `cocomon_tpose.blend`，为这只角色制作 **4 个动画 Action**：

| Action 名 | 内容 | 时长（24fps） | 循环要求 |
|---|---|---|---|
| `IDLE` | 待机呼吸循环 | 48–96 帧 | 完美循环 |
| `TALK` | 自然说话的状态（日常聊天的感觉），有语气起伏和重音 | 48–96 帧 | 完美循环 |
| `JUMP` | 原地跳跃：起跳 → 腾空 → 落地 → 收势 | 24–72 帧 | 首末帧姿态一致（可从 IDLE 接入、落回 IDLE） |
| `EMOTE` | **困倦伸懒腰**：打瞌睡 → 猛然惊醒 → 展臂伸个懒腰 → 恢复精神 | 24–120 帧 | 首末帧姿态一致 |

## 二、交付物

- **`cocomon_animated.blend`**：在原始文件基础上制作，4 个 Action 全部保存在文件内（可在 Action 编辑器/NLA 中找到，命名严格同上表）。⚠ 注意：Blender 保存时会清除"无使用者"的 Action——交付前请重新打开文件，确认 4 个 Action 都还在（给 Action 点 Fake User 盾牌，或 stash 进 NLA）。
- **不需要渲染视频**。你制作过程中可以用静帧渲染自检（场景是 EEVEE，很快），但不必交付渲染结果。
- 可选附上你制作过程用的脚本/笔记，仅供复盘参考，不参与评分。

## 三、硬性要求（客观检查，不满足直接出局）

1. **循环闭合**：`IDLE`/`TALK` 首帧与末帧的全部骨骼姿态逐一致；`JUMP`/`EMOTE` 首末帧为同一站立姿态。
2. **不改资产**：骨骼数量/层级/命名、网格顶点数、绑定关系保持原样；不新增/删除骨骼，不加形态键。
3. 帧数在上表范围内。

## 四、质量导向（重要）

硬性要求只是**及格线**。评分的重心在动画本身的表现力：

- **达到基础要求后，请尽可能发挥能力，让角色动起来生动、自然、有性格。** 平庸但合规的作品只能拿到底分。
- 骨骼清单里有的东西，评委都期待看到它被使用——**先自己打开 blend 摸清这只 rig 提供了什么**，再动手。
- `EMOTE` 题目固定，但演绎方式自由：困意有多重、惊醒有多猛、懒腰伸多开，都是展现角色性格的空间，做完整、做夸张都可以。
- 评分维度：生动性 / 动作流畅度 / 重量感与物理可信度 / 细节层次 / 动作可读性。
