# 质检参考线

`make.py` 跑完会打印一份报告，`python scripts/qa.py <wav>` 可随时重看。下面是读这份报告时用的参考线——都是这套工具在实测里调出来的经验值，不是行业标准，**先当路标，不当红线**。

## 一眼四项

| 指标 | 参考区间 | 偏了怎么改 |
|---|---|---|
| 时长 | 与 `--seconds` 一致；原始渲染比 MIDI 长 5~7s（释放 + 混响余响）属正常 | 短于 `--seconds` 说明 MIDI 被截断：查 `BARS` 与 `--seconds` 是否匹配 |
| 峰值 / clipping | 归一化后 peak ≈ 0.89；`clipping_samples = 0` | 有削波就降 `--gain`（默认 0.6），别靠削波换响度 |
| RMS | 整体约 −18 ~ −12 dBFS；**每秒 RMS 轮廓要有起伏**，全程一条直线＝没有层次 | 拉开各声部力度（velocity）差异，别全用同一个值 |
| 开头 | 第 1 秒不应低于约 −40 dB | 开头太低听着像坏文件：加低音长音（主音/五度 drone）托底 |

## 立体声

| 指标 | 参考 | 说明 |
|---|---|---|
| `lr_corr` | **0.60–0.85** | 1.0 = 单声道；0.94 以上说明只靠 CC10 pan，宽度不够 |
| 做宽的三件套 | 极端 pan（≤15/≥110）+ 左右分轨 + `--width` M/S 展宽 | 单独用任何一个都不够 |

## 无缝循环

| 指标 | 参考 | 说明 |
|---|---|---|
| `seam_ok` | `true` | 判据：接缝跳变 ≤ 相邻样本差分的 99.99 分位 × 1.5，或 < 0.02 |
| `seam_step` | 越小越好 | `false` ＝ 循环接缝可能听到咔哒 |

只能用 tail-fold 处理接缝（`--seconds` 已实现）：把渲染尾巴的余响折回开头。**不要用淡入淡出糊过去**——循环播放时淡入淡出本身就是可听的瑕疵。

## 频段占比

| 频段 | 参考 | 听感对应 |
|---|---|---|
| 80–250 Hz | ≥ 8% | 低于 8% 就是「薄」，最常见的毛病；补低音声部或低八度和弦 |
| 250–800 Hz | 别堆积 | 所有声部挤在这个区一定「糊」；把各声部音区拉开 |
| 2500–6000 Hz | 有内容 | 全空会显得闷；少量高频（铃、拨弦、镲）提亮 |
| 6000–16000 Hz | 少量 | 过多会刺 |

## 打击乐

GM 打击乐固定走通道 9，音高＝鼓件号不是音高。`p.track(..., drums=True)` 已处理；直接写 `p.track()` 会占用普通通道。
