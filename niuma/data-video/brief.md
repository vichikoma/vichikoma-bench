# 本次汇报的背景

> 本文件 + `brand.md` + `data/` 是「可替换」部分：换成你自己的公司、期间和数据即可，`TASK.md` 不用改。

## 公司与场景

你是连锁咖啡品牌「牛马咖啡」总部的运营分析。周一的季度经营会上，老板要在开场放一支动态数据短片，让全员在半分钟内看清：**2026 年第三季度（7–9 月）公司经营得怎么样**。

你手上只有一份从业务系统导出的明细数据，没有人帮你整理。

## 汇报期间

2026 年第三季度（2026-07 至 2026-09）。

## 成片时长

30 秒 ±2 秒。

## 数据

| 文件 | 说明 |
|---|---|
| `data/sales_2025-01_2026-09.csv` | 2025-01 至 2026-09 的月度经营明细，系统原始导出、未经清洗 |

字段：

| 字段 | 含义 |
|---|---|
| 月份 | YYYY-MM |
| 大区 | 华东 / 华南 / 华北 / 华中 / 西南 |
| 品类 | 经典咖啡 / 创意特调 / 茶饮 / 轻食 / 周边 |
| 渠道 | 门店 / 外卖 |
| 销售额(元) | 当月该组合的销售额 |
| 订单数 | 当月该组合的订单数 |
| 毛利(元) | 当月该组合的毛利 |
